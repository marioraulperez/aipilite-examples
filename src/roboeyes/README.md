Animated robot eyes on the 128×128 face display using a vendored [FluxGarage RoboEyes](https://github.com/FluxGarage/RoboEyes) (v1.1.2, patched for square screens).

- **Button A**: cycle mood (default → tired → angry → happy)
- **Button B**: play animation (laugh / confused)

```sh
# build & upload
pio run -e roboeyes -t upload
```
